# TaskMatrix Wireframes

These wireframes are the Phase 2 (P1) UI/UX deliverable for the TaskMatrix Agile Project Management capstone. They were designed before implementation and represent proposed layouts, not a running application.

## Core Viewports

The Figma file contains four desktop frames, each 1440 × 900:

1. **01 — Authentication:** login and account-creation entry point.
2. **02 — Dashboard:** project/task summary, recent tasks, and project progress.
3. **03 — Project Board:** Backlog, To Do, In Progress, Review, and Done workflow columns.
4. **04 — Task Details:** task description, status, priority, assignee, due date, labels, comments, and save action.

## Scope

This repository currently contains planning documentation and exported architecture diagrams. The wireframes are design mockups; their controls are not connected to a working application yet.
